# Rajpoot Rice Mills Pvt Limited

Company website built with React, Vite and Tailwind CSS v4.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build for production

```bash
npm run build
```

The finished site is written to `dist/`.

## Where things live

- `src/data/content.js` – all text: products, address, phone, hours, recipes, testimonials
- `public/images/` – photos (slider, products, processing steps, recipes, certificates)
- `src/pages/` – one file per page
